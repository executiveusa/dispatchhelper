# Contract generator source lock

The handoff requires the contract generator to be built from the **On Shore template**.

That source template is not present in the repository or the supplied handoff. The code therefore does **not** invent legal clauses. `src/services/contract-generator.ts` only performs the corrections explicitly authorized in the handoff and requires the owner-approved template text at runtime.

Required corrections:
- weekly rate = 5 × daily rate;
- the known $3,457.50 weekly typo becomes $3,547.50 when the daily rate is $709.50;
- remove leftover "The Weitz Company" reference;
- remove "Association" language;
- use an owner-confirmed renewal year;
- owner's attorney reviews legal clauses.

Do not place a contract into customer use until the source template has been supplied and the resulting draft has been reviewed.
